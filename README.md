## 📌 О проекте

**VoxP2P** — это открытый (Open Source) кроссплатформенный мессенджер для голосового общения и обмена сообщениями, работающий по принципу **чистого P2P (Peer-to-Peer)**. 

В отличие от традиционных мессенджеров (Discord, Telegram, WhatsApp), в VoxP2P **полностью отсутствуют центральные серверы**, базы данных компаний или облачные провайдеры. Все коммуникации происходят исключительно напрямую между устройствами пользователей.

* **Без регистрации:** Никаких номеров телефонов, email или паролей.
* **Криптографическая идентификация:** Вашим адресом является криптографический публичный ключ Ed25519 (User ID).
* **Полная приватность:** Никто, кроме вас и вашего собеседника, не имеет доступа к переписке, файлам и звонкам.

## ✨ Основные возможности

* 🔊 **Голосовая связь без задержек:**
  * Прямые звонки 1-на-1 (Direct Calls) и групповые голосовые комнаты (Voice Rooms).
  * Кодек Opus с адаптивным битрейтом и фреймами по 20 мс.
  * Интеллектуальное шумоподавление на основе нейросети (`nnnoiseless`).
  * Индивидуальная регулировка громкости каждого собеседника и индикация активности речи.

* 💬 **Прямой обмен сообщениями (Direct Messaging):**
  * Мгновенный обмен зашифрованными сообщениями напрямую через QUIC.
  * Очередь исходящих сообщений (**Store-and-Forward Outbox**): если собеседник не в сети, сообщение сохраняется локально и автоматически доставляется сразу после его появления онлайн.
  * Подтверждения о доставке (Delivery Acks), редактирование и удаление сообщений.

* 📁 **P2P-передача файлов и медиа:**
  * Отправка файлов любого типа и размера без ограничений серверов.
  * Автоматическая проверка целостности на базе криптографического хэширования BLAKE3 (`iroh-blobs`).
  * Фоновая синхронизация и кэширование аватарок контактов.

* 📱 **Синхронизация между устройствами (Device Pairing):**
  * Быстрый перенос контактов и истории переписки между вашим ПК и другими устройствами по QR-коду.
  * Прямой защищенный бинарный протокол синхронизации в локальной сети или через Интернет.

* 🔒 **Локальная безопасность:**
  * Шифрование локальной базы данных SQLite ключом, привязанным к профилю пользователя.
  * Отсутствие единой точки отказа и невозможность блокировки центрального узла.

* 🖥️ **Удобство использования:**
  * Сворачивание в системный трей (Tray Icon) с возможностью быстрого вызова.
  * Защита от запуска дублирующих процессов (Single Instance).

## 🛠️ Как это работает (Архитектура)

Архитектура VoxP2P построена на стеке современных сетевых и криптографических протоколов:

```
+-------------------------------------------------------------+
|              Пользовательский интерфейс (UI)                |
|               Svelte 5 (Runes) + TypeScript                 |
+-------------------------------------------------------------+
                              ↕ IPC (Tauri v2)
+-------------------------------------------------------------+
|               Ядро приложения (Rust Engine)                 |
|  +--------------------+  +-------------------------------+  |
|  |   Аудио-пайплайн   |  |     Сетевой модуль Iroh       |  |
|  | CPAL + Opus + RNNoise| |  QUIC + NAT Hole Punch + DERP |  |
|  +--------------------+  +-------------------------------+  |
|  +--------------------+  +-------------------------------+  |
|  | Хранилище (SQLite) |  |   Контент-адресация (Blobs)   |  |
|  |  Зашифрованная БД  |  |     BLAKE3 Verified Storage   |  |
|  +--------------------+  +-------------------------------+  |
+-------------------------------------------------------------+
```

### 1. Установление P2P-соединений (Iroh QUIC)
Каждый узел генерирует уникальную пару ключей Ed25519 при первом запуске. Соединение между пирами устанавливается по протоколу **QUIC**:
* Для преодоления межсетевых экранов (NAT/Firewall) задействованы механизмы STUN и прямого пробития портов (Hole Punching).
* В случаях симметричного NAT используется шифрованная сквозная ретрансляция DERP (Relay), при которой ретранслятор передает только зашифрованные пакеты и не имеет ключей для расшифровки.

### 2. Безопасность и шифрование данных
* Все сетевые пакеты шифруются по стандарту **TLS 1.3** с двусторонней аутентификацией открытыми ключами пиров (Mutual Authentication).
* Голосовой трафик передается напрямую между пирами в виде легковесных датаграмм QUIC без промежуточного декодирования.
* Локальные сообщения, метаданные контактов и настройки сохраняются в зашифрованном локальном файле SQLite.

### 3. Обработка звука (Audio Pipeline)
1. Захват аудиопотока с микрофона с помощью библиотеки `cpal`.
2. Фильтрация фонового шума и эха через нейросетевую модель `nnnoiseless`.
3. Кодирование пакетов в оптимизированный голосовой формат `audiopus` (Opus) порциями по 20 миллисекунд.
4. Прямая передача собеседникам, буферизация в кольцевой джиттер-буфер (`ringbuf`) и воспроизведение через выходное устройство.

## 💻 Технологический стек

* **Frontend:** [Svelte 5](https://svelte.dev/) (с новой системой реактивности Runes), TypeScript, Vite.
* **Desktop Shell:** [Tauri v2](https://v2.tauri.app/) (легковесная и безопасная альтернатива Electron).
* **Язык бэкенда:** [Rust 2024](https://www.rust-lang.org/).
* **P2P-сеть:** [Iroh](https://iroh.computer/) (`iroh`, `iroh-gossip`, `iroh-blobs`).
* **Аудио:** `cpal`, `audiopus`, `nnnoiseless`, `ringbuf`.
* **База данных:** SQLite / SQLCipher (`rusqlite`).

## 🚀 Сборка и запуск для разработчиков

### Предварительные требования

1. **Node.js** (версия 18 или новее) и менеджер пакетов `npm` / `pnpm`.
2. **Rust** (актуальная стабильная версия `stable`, установите через [rustup](https://rustup.rs/)).
3. **C++ Build Tools** (для Windows: Visual Studio C++ Build Tools).

### Пошаговая инструкция

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/VoxP2P.git
   cd VoxP2P
   ```

2. Установите зависимости фронтенда:
   ```bash
   npm install
   ```

3. Запустите приложение в режиме разработки с горячей перезагрузкой (Hot Reload):
   ```bash
   npm run tauri dev
   ```

4. Сборка оптимизированного релизного дистрибутива:
   ```bash
   npm run tauri build
   ```
   Готовый установщик и исполняемый файл будут находиться в папке `src-tauri/target/release/bundle/`.
